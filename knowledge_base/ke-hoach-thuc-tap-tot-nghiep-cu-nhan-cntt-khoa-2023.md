# Kế hoạch thực tập và khóa luận Cử nhân CNTT khóa 2023

## Các mốc Cử nhân CNTT niên khóa 2023–2027

| Công việc | Thời gian |
| --- | --- |
| Đăng ký thực tập online | 26–28/10/2026 |
| Thực tập 7 tuần | 11/01–14/03/2027, nghỉ Tết 01–14/02 |
| Đánh giá thực tập | 15–21/03/2027 |
| Xét điều kiện tốt nghiệp và thực hiện khóa luận | 22–28/03/2027 |
| Giao khóa luận, đăng ký học phần tốt nghiệp | 29–31/03/2027 |
| Thực hiện khóa luận hoặc học phần thay thế | 05/04–13/06/2027 |
| Bảo vệ khóa luận | 14–30/06/2027 |
